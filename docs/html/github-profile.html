🚀 Quick start

Install the defstack CLI and bring up the trust core in under a minute:

bash — one-liner install
# Option A — install script (macOS / Linux / WSL)
$curl -sSL https://get.warrantor.dev | sh
# Option B — Rust workspace (trusted core)
$cargo add aumos-trust-core
# Bring it up and run the cross-language conformance suite
$make conformance

🧭 The 12-plane architecture

One trusted Rust core. Twelve planes. Every action flows top-to-bottom through identity, authority, evidence, enforcement, and audit. No security invariant has two authoritative implementations.

AumOS · 12 planes · 1 trusted core
P1Identityagent-identity · SPIFFE SVID
P2AuthorityAAE envelope · delegated authority
P3Evidenceflight-recorder · signed AAR · Sigstore
P4PolicyRego + Cedar + OpenShell profiles
P5Runtimesecure-workspace · eval-guard
P6Sandboxcredential-vault · egress-filter
