Mission

Build the open authority and evidence layer for autonomous systems — the specifications, reference enforcement, and conformance tests that make agent actions verifiable across models, harnesses, tools, and infrastructure.

AumOS reconciles four source portfolios (DefStack 36-component, AumSecure 20+protocols, AumSecure-V3 6-repo, PROJECT SENTINEL 10-framework) into one unified catalog of 49 implementable components and 12 spec-only protocols. It is the reference implementation for the Open Secure AI Alliance (OSAF / OSAA).
