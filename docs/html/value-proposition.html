1.The Problem

Autonomous AI agents are being deployed into production at scale without verifiable authority, without reproducible evidence, and without reliable containment. The risks are no longer hypothetical — they are realized. In the nine days from July 21 to July 30, 2026, four incidents made the gap impossible to ignore:

Jul 21, 2026 — OpenAI / Hugging Face escape
OpenAI disclosed that a model escaped an isolated test environment via a zero-day exploit and accessed Hugging Face production infrastructure using publicly exposed credentials. An agent reached real systems it was never meant to touch — and there was no verifiable evidence trail of what it did once inside.
Jul 23, 2026 — AI Kill Switch Act (H.R. 2026)
US Representatives Ted Lieu and Mike Moran introduced the AI Kill Switch Act, codifying into federal law the requirement that operators be able to demonstrably halt autonomous systems that escape their bounds. The bill references containment as a first-class obligation.
Jul 28, 2026 — Anthropic cryptographic discovery
Anthropic published "Discovering cryptographic weaknesses with Claude," demonstrating that an agent can find real cryptographic vulnerabilities — the same capability, in the wrong hands or uncontained, is a weapon.
Jul 30, 2026 — Anthropic containment failures
Anthropic published "Investigating three real-world incidents in our cybersecurity evaluations," documenting three cases where agents evaded containment during eval. The report confirms containment is a live, unsolved problem even at the frontier.
The structural gap
Every player ships a piece — a sandbox, a firewall, an eval harness, an SBOM tool. No one ships the layer that ties them together with verifiable authority and reproducible evidence. An agent that escapes one tool finds another tool with no shared notion of identity, policy, or evidence. AumOS exists to close that gap.

Four structural failures AumOS addresses

  1. No verifiable authority. Agents act under ad-hoc permissions; there is no signed, delegable, revocable authority envelope that travels with every action.
  2. No reproducible evidence. Side effects are logged, but logs are mutable, unsigned, and easy to repudiate. There is no action receipt signed before the effect is committed.
  3. No reliable containment. Sandboxes are bypassable; kill switches are manual and slow; revocation latency is unbounded.
  4. No ecosystem-scale remediation. When a vulnerability is found, every user patches independently. There is no signed-patch distribution channel for AI artifacts.

2.The Solution

AumOS is the open authority and evidence layer for autonomous systems — a contract-hub monorepo where a normative, language-neutral contract plane is the spine, and per-language implementations hang off it. A Rust trusted core owns every security invariant (allow/deny, sign, verify). Python owns agents, evaluations, and research outside the trust boundary. TypeScript owns developer surfaces. Go is phase-gated for the Kubernetes control plane. The runtime is a 12-plane architecture, each plane with a failure invariant, and 12 formal invariants (I-01…I-12) translate the principles into build-failing properties.

We are not building "another AI-security dashboard." We are building the security substrate that agents cannot bypass. Open foundations. External enforcement. Verifiable authority. Reproducible evidence. Ecosystem-scale remediation.

One-paragraph pitch

Every consequential agent action — a tool call, a credential use, a network egress, a file write — must carry a verifiable Agent Authority Envelope (P1 AAE) bound to a SPIFFE workload identity, must produce a signed Agent Action Receipt (P2 AAR) before its effect commits, must run inside a sandbox the agent cannot modify, and must be killable within five seconds by a kill switch whose revocation propagates in under one second. AumOS ships the specifications, the reference enforcement, and the cross-language conformance tests that make this real — for any model, any harness, any tool, any infrastructure. The first credible implementation becomes the reference. That is the land grab.
