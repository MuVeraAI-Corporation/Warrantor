Observed ≠ Enforced

The warrant crate’s own type system is the honesty mechanism. BoundStrength in aumos/rust/warrant/src/lib.rs is three-valued on purpose. Collapsing Mediated into Enforced is how a developer reads “the agent is bounded” and believes there is a cage. read path

BoundStrengthWhat actually holds itWhat does not
tools Mediated MCP proxy proxy::decide on calls that traverse warrantor mcp --agent Any built-in file/shell tool a coding agent never sends through MCP
write_paths Observed Worktree isolation plus settle-time Worktree::commit_all staging only in-bounds paths No refuse at write. proxy.rs contains no path logic. An agent can write tests/__pycache__/ under a src/** grant.
egress_hosts Mediated Proxy + egress.rs on MCP-routed destinations No netns, no seccomp, no firewall. Shell access reaches the network without the broker.
staged_classes Mediated Proxy stages the four GitHub tools in EffectRegistry::github() Unknown tools are not staged. Forwarded upstream tools run rather than queue unless classified.
expires_at Enforced OS process link: Windows job object, Linux setsid + PR_SET_PDEATHSIG in supervise.rs In-flight MCP sessions outside the supervised tree; platforms where linkage does not survive supervisor death
delegation_depth Enforced Ed25519 over warrant claims; a child cannot hold what its parent did not —
budget_cents_observed Observed spend.rs ledger of what the agent reports Provider API calls never pass through Warrantor. An agent that does not report spends invisibly. A refuse does not undo the provider call.

warrantor sandbox derives a confinement profile. It does not move a single entry in bound_strengths(). A test asserts that. A profile that is never launched confines nothing. That sentence is load-bearing for every “sandbox” claim below.

Rust warrant spine

Package warrantor-warrant at aumos/rust/warrant. This is the product. Seven external crates, tokio-free, custom CLI parser (no clap). The binary is aumos/rust/warrant/src/bin/warrantor.rs. read path

Commands that exist

Top-level match in main: grant, list, holdings, prune, report, verify, issuer, archive, egress, spend, stop, settle, void, stage, run, supervise, status, mcp, operator, approve, queue, sandbox, agents, guard, anchor, selftest-upstream, serve, console, help. Nested: issuer add|list|remove|show-hex|export|import; archive enrol|push|fetch|list|auto|summary; guard doctor|bench|export-corpus; operator list|add|remove|session-scope; agents list|detect|show|wire; anchor show|verify. supervise is implemented and not listed in the binary’s USAGE block. That is a documentation defect of the same class tests/instructions.rs exists to catch for flags; it is not a missing command.

Grant / verify / store

Warrant::grant signs bounded authority. IDs are wrt_ plus eight CSPRNG bytes — the previous one-second clock silently destroyed the first of two grants in the same second. Keys: issuer.key mints, settle.key releases, device.key only after archive enrol. serve deliberately does not call load_or_create_key. Default subject spiffe://muveraai.com/agent/local is a placeholder, not an identity. Tests: aumos/rust/warrant/tests/warrant.rs, identity.rs.

Serve, console, TLS

aumos/rust/warrant/src/serve.rs is HTTP/1.1, thread per connection, Connection: close, any Transfer-Encoding is 400. No keep-alive, no HTTP/2, no change-feed, no grant route. Bearer token is checked before route resolve. Unauthenticated assets: /, /index.html, /console.css, /console.js — compiled into the binary, no store-derived templating.

Authenticated routes (Target enum + handle_scoped): GET /v1/health, GET /v1/warrants, GET /v1/warrants/{id}, …/report|effects|refusals|evidence, POST …/settle|void|stop|approve, GET /v1/queue, GET /v1/warrants/{id}/custody, GET /v1/summary/refusals, GET /v1/summary/daily. Unrecognised query keys are 400. The list route used to ignore ?since=; that was a real defect and is fixed at the source.

TLS lives in aumos/rust/warrant/src/tls.rs behind --features tls, flags --tls-cert / --tls-key, both-or-neither. rustls was already in the tree via ureq. A failed handshake gets no HTTP reply. No certificate is issued, renewed, or name-checked. Bind beyond loopback without TLS is a refusal unless --i-accept-cleartext-on-this-network.

The live UI is aumos/rust/warrant/src/console/, not the TypeScript package. It polls every five seconds. It does not verify signatures. Token lives in the URL fragment.

MCP proxy and upstream

mcp.rs is JSON-RPC 2.0 over stdio. Control endpoint publishes lifecycle tools (warrant_grant|status|report|stop|settle|void). Agent endpoint never publishes those. proxy.rs decides Forward / Stage / Deny. Staging registry knows four tools: github.create_pr, github.comment, github.request_review, github.add_label — EffectRegistry::github() in aumos/rust/warrant/src/staging.rs.

upstream.rs is a synchronous MCP client over a child process. Repeatable --upstream 'name=command args'. Upstream schemas are published verbatim as <name>.<tool>. An upstream that publishes warrant lifecycle verbs is refused at attach. --upstream-class and --upstream-refuse-unclassified replace the old Read-guess. Registry still wins over a declaration, because only those four tools can actually be performed at settle. selftest-upstream is a two-tool server built into this binary so forwarding tests spawn a real child.

Forwarding mediates MCP, and MCP only

Every terminal coding agent ships file, edit and shell tools that never traverse an MCP server. Wiring buys the deadline, the worktree, staged effects, evidence, the OS lifetime link, and mediation of MCP tools. It is not mediation of bash.

Operators, review, notify

operators.rs: named principals, tokens stored as SHA-256 and printed once, scopes read,stop,settle,approve, registry reread per request. Actor log actors/<id>.jsonl is hash-chained. Approval policy in approvals.json. Deadlock is a first-class answer. One anonymous warrantor approve under required > 1 used to make a warrant permanently unsettleable; the CLI now refuses the act.

review.rs derives GET /v1/queue — there is no queue.json. you_can is computed server-side. Console “Waiting on you” is a viewer of that. notify.rs fires settled, voided, stopped, filing-queued, and review-requested. HTTP/console now notify via StoreApi::with_notifier. Commands in notify.json run only when the invocation carried --allow-notify-command — a file write cannot arm them, because the supervised agent shares this UID.

Archive client and autofile

archive_client.rs is the single definition of the Warrantor-Device header. CLI: enrol, push (verbatim + digest check), fetch (digest check), list, summary, auto settle|off. Automatic push on CLI settle exists: failed filing does not fail settle; queue is archive/pending.jsonl; next settle is the retry; no daemon. serve.rs has no autofile reference. HTTP and MCP settle do not auto-file. read path

Sandbox

sandbox.rs emits argv for bubblewrap or firejail. It does not spawn them. No-egress warrants get --unshare-net. Host-allowlisted warrants get no netns (that would be stricter than the warrant). Glob refinement inside the worktree is not expressed. Windows worktree paths are refused before a command is printed. Module docs record a 2026-08-17 Linux 6.18 run that held three claims and disproved the fourth: /tmp is a tmpfs, writes succeed and vanish. That observation is not re-verified in this session. unverified this session

Guard attach

guard.rs is observe-only by default. Attach behind warrantor mcp --agent <id> --guard. Signals in <root>/guard/<id>.jsonl. A model without a digest refuses to attach. Enforcement exists behind --guard-enforce-untested-do-not-use and is named that way because Qwen3Guard is a general safety classifier: it caught rm -rf and missed a force-push rewrite of main. Bounds refuse first; the model comments on what bounds allowed. Published figures 0.8152 recall / 0.0923 FPR are about WildGuardTest, not live traffic.

Spend, stop, report, worktree, daemon, retention, runs, corpus, trust, bundle, anchor

  • spend.rs — durable ledger; absent cap is zero, not unlimited; Observed.
  • stop.rs — kill supervisor group; structurally cannot claim PASS on elicitation; daemon socket is never bound by this crate.
  • report.rs — copies bound_strengths() verbatim; a test forbids upgrades.
  • worktree.rs — branch prefix warrantor/; settle never removes a worktree, only void does.
  • daemon.rs — run / supervise / status; no resume after supervisor death.
  • retention.rs — holdings lists every ArtifactClass exhaustively (compiler-caught when actors/, runs/, reviews/ landed). prune dry-run by default; deletes only NoIntegrityConsequence (logs/, reviews/).
  • runs.rs — positive record of an unguarded session so “nobody watched” ≠ “nothing ran”.
  • corpus.rs — export never uses the guard’s own verdict as a label.
  • trust.rs / bundle.rs — local TOFU pins; carried signed bundle; no network directory; no revocation channel.
  • anchor.rs — relative order, not absolute time. Head digest is publishable by a human.
