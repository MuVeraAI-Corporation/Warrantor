Thesis

Logs are not evidence. Evidence is signed, audience-aware, retention-scoped, and mappable to incident taxonomies. Warrantor evidence plane centers on E1 flight-recorder emitting P2 AAR, with context/memory integrity (P3/P4) and incident exchange (P9 / X9).

1. From telemetry to evidence

OpenTelemetry’s GenAI observability work standardizes spans for agents[1]. OWASP AOS pushes agent-specific trace semantics and OCSF extensions[2,3]. That is necessary transport. Warrantor adds cryptographic receipts: COSE-signed action records[7] with transparency-log DNA[8].

2. Agent Action Receipt

P2 AAR binds: who (AAE ref), what (tool/args hash), when, decision (allow/deny), policy version, and CAP snapshot. E1 flight-recorder is the emitter; NOOA audit streamers (X2) can forward without becoming dual verifiers—T1 remains signature authority.

3. Context & memory integrity

Warrantor-native (P3 / P4)

P3 CPE and P4 AMIL are Warrantor compositions. Foundations: W3C PROV[6] and Merkle transparency designs[8]—not identical public standards under those names.

CPE sketch: each retrieved chunk carries source_uri, content hash, ranker id, and policy tags (PII class). The agent’s context window is then a PROV-style derivation graph: query → retrieval set → prompt assembly → model call. Without CPE, RAG poisoning is untraceable.

AMIL sketch: memory write ops append (prev_root, op_hash, ts, sig). Fork/merge of agent memory requires explicit root compare—silent overwrite is a deny. “Agent forgot” becomes a ledger question, not a vibe.

4. Incident exchange

X9 + P9 normalize agent incidents onto OCSF classes[4] with MITRE ATLAS technique tags[5]. That enables SIEM federation without inventing a proprietary JSON every vendor ignores. Minimum AIX fields: severity, technique ids, linked AAR jtis, affected tenants, and share boundary (internal vs ISA). Retention and redaction are first-class—DPDP and sectoral rules will punish “store full prompts forever.”
