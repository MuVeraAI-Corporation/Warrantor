## Decisive Warrantor implications

### Claims that should be retired or rewritten now

1. **“Nobody else builds delegation-chain intersection.”** Cloudflare explicitly computes a capability ceiling by intersecting multiple authority inputs, while SentinelAgent implements monotonic chain narrowing and SAGA implements agent-specific cryptographic authorization. The reproduced SentinelAgent artifact is not equivalent—its delegation is bearer-only, output authority is unsigned and its formal model has no multi-principal composition—but it still defeats the universal absence claim. Warrantor may differentiate on exact algebra, holder authentication, multi-principal composition, cross-stack enforcement, receipt binding and proof-to-code correspondence.
2. **“No execution-count-bounded agent authorization has been designed or implemented.”** SAGA provides peer-reviewed open design and code for request-count-plus-expiry tokens, so the broad claim must be retired. Its pinned implementation nevertheless admitted two requests from quota one and does not specify durable release consistency. The narrower “no measured open-source SLA” proposition remains unresolved, not proven. Warrantor's defensible target is a linearizable, durable and independently measured residual-action and propagation guarantee across every authoritative enforcement point.
3. **“No implementation anywhere” across the six additions.** Several additions have direct or partial prior art; each needs its own feature-bounded novelty statement.
4. **Mandato as evidence of a completed competing product.** It is strong design prior art, but its empirical evaluation and end-to-end demonstration are future work.
5. **A producer-signed receipt as sufficient independent evidence.** Sello shows why a compromised producer/operator can fabricate or omit self-reported evidence. Warrantor needs optional receiver, gateway, TEE or witness corroboration and an explicit completeness model.
6. **“Nobody signs evals or pins the grader.”** Attestable Audits binds the model, audit code, data and result to TEE evidence; the auditable grant-evaluation design signs and timestamps model/rubric/input/output; Aqta implements signed, cross-language gateway/action records; and Every Eval Ever provides the strongest reviewed cross-harness semantic substrate. Warrantor must make a narrower claim about authenticated authority-linked evaluation evidence, measured conversion loss, completeness, independent corroboration and production operation.
7. **The former broad governance portfolio as uncontested open-source territory.** Microsoft Agent Governance Toolkit overlaps policy, identity, delegated trust, sandboxing, kill switches, audit, reliability and cross-language integration. Its public-preview and host-boundary limitations leave room for Warrantor, but they remove the basis for broad absence claims.
8. **A green internal test suite as proof of external interoperability.** Aevum reproduces extensively but its Rekor v2 tests mock a v1-shaped contract at the v2 URL. Warrantor needs fixtures derived from normative external types and at least one real-service or independent implementation test.
9. **A named TLA+ property as proof of the corresponding runtime behavior.** SentinelAgent's 2.7-million generated-state run reproduces, but P3 copies a policy set, P4 uses arithmetic, P5 revokes finite state atomically, and P6/P7 narrow sets without an action or output value. The Python path simultaneously leaves output authority unsigned and expiry unenforced. Warrantor must publish formula, bound, assumptions and proof-to-code mapping separately.
10. **“AuthZEN/COAZ-compatible” as proof of non-bypassable MCP enforcement.** AuthZEN standardizes a decision exchange and explicitly trusts the PEP to supply correct inputs and enforce the result. COAZ-MCP Draft 1 omits three valid MCP 2026-07-28 core requests and wildcard-passes every notification. Executable review strengthens the warning: Vengtoo's nominal AuthZEN request is rejected by both Cerbos and OpenFGA; Cerbos FastMCP leaves retrieval/template hooks unmediated and executes arguments mutated after authorization. Warrantor must separately prove final wire shape, target semantics, current method coverage, mapping provenance, immutable operation binding, atomic consumption, complete routing and result/effect linkage.
11. **“Nothing tests an authority substrate's invariants.”** SentinelAgent directly tests its own delegation service and ASB/AgentFuzz/AgentDojo/Chord/ToolHijacker provide substantial adjacent corpora. The broad absence claim is false. The defensible opportunity is an independently authored, cross-implementation profile with exact authority→decision→permit→wire→effect assertions, semantic utility, mutation score and adaptive repeated attacks.
12. **“No kill-switch conformance suite exists anywhere, despite legislated capabilities.”** KillBench, SANDBOXESCAPEBENCH, ContainmentBench, VIGIL, the US–UK AISI shutdown-avoidance evaluation and shipping cloud/runtime response mechanisms defeat the literal absence claim while testing different layers. H.R. 9917 was introduced, not enacted, and provides no `<5s` conformance schema. Warrantor may differentiate only on the exact effect-observed four-capability C5–C7 composition after it exists.
