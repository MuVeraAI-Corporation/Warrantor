## Non-negotiables carried into every piece

1. **US English**, verified by machine, not by eye:
   ```bash
   node "M:/Project AumOS - Linkedin Blitzkrieg/scripts/verify-us-english.mjs" <file...>
   ```
2. **Primary markets are US/NA, GCC and India.** The EU never leads; passing mention only where
   factually required.
3. **SR 11-7 is superseded.** Cite *OCC Bulletin 2026-13 / Fed SR 26-2, 17 April 2026*.
4. **Name the record, never judge the company.** Cite the vendor's own published document alongside
   every name; describe by class anything not self-disclosed. People are never named critically.
5. **Authenticity contract.** The ideas and the voice are Vikram's; every piece is approved by him.
   AI assists structure, polish and visuals only.
6. **No claim outruns its mechanism.** Every guarantee stated in prose must have an assertion behind
   it, or be labeled as an argument rather than a result.

## Three corrections this program makes to prior assumptions

- **The estate is not empty.** 24 papers, 8 blog articles, 101 sources, 65 RFCs and 120 business
  topics already exist. The catalog is dispositioned against them, not written past them.
- **RBI FREE-AI is from August 2025**, not 2026 — and a **June 2026 RBI draft** now supersedes it as
  the live consultation surface.
- **USENIX Security '27 Cycle 1 closed on 25 August 2026**, five days before this program was built.
  The only hard academic deadline in the window is **IEEE S&P 2027 Cycle 2 — 17 November 2026**.
